# Topics deliberately NOT in the knowledge base
These must trigger escalation. Used to write escalation test tickets in Step 2b.

1. Firmware updates: how to check or upgrade the drive firmware.
2. Fieldbus/network communication: setting up serial or Ethernet communication with a PLC.
3. PID closed-loop control: using the drive for pressure or flow regulation.
4. External braking resistors: connecting and setting up a braking resistor.
5. Single-phase supply operation: running the drive from a single-phase or 230 V supply.
